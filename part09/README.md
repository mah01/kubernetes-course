# A. Job

## exercise 01: Job

1. Create a Job that runs a simple command
   * Example:
     * `echo Hello from Job!`
2. Apply the configuration
   * `kubectl apply -f job.yaml`
3. List Jobs
   * `kubectl get jobs`
4. List Pods
   * `kubectl get pods`
5. Inspect logs
   * `kubectl logs <pod_name>`
6. Does the Pod complete?
